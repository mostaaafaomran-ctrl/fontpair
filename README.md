# FontPair AR

Preview Arabic Google Fonts with your text and get Latin pairings.

**Live: https://mostaaafaomran-ctrl.github.io/fontpair/**

Type your Arabic text, see it in 24 Google Arabic fonts, pick a Latin pair and copy the CSS.

## Features

- 24 Arabic Google Fonts, filter by style, size and weight
- 3 suggested Latin pairings per font
- Live pair preview and one-click CSS copy
- Fonts load from Google Fonts, the rest runs locally

## Run locally

No build step. Open `index.html` in a browser, or serve the folder:

```bash
npx serve .
```

## Privacy

Everything runs in your browser. Nothing is uploaded and there is no account.

## العربية

جرّب نصك العربي بـ24 خط من Google Fonts، واختار خط لاتيني مناسب وانسخ الـCSS.
